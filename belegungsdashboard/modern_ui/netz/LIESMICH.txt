INNternat im gemeinsamen Netzwerkordner
=======================================

Aufbau
------
  INNternat\
    INNternat starten.bat   <- jeder PC startet INNternat hierüber
    LIESMICH.txt            <- diese Datei
    Programm\               <- das Programm (wird bei einem Update ersetzt)
    Daten\                  <- die gemeinsamen Daten aller PCs (entsteht beim ersten Start)

PCs ohne Python (ab 1.38.1)
---------------------------
Das Zip "INNternat_Python.zip" einmal in diesen Ordner entpacken - es legt den Ordner "Python" neben
"INNternat starten.bat" an (ca. 320 MB, Python 3.13 mit allen Paketen). Dann braucht KEIN PC eine Python-Installation.
Beim ersten Start kopiert jeder PC dieses Python einmalig zu sich (%LOCALAPPDATA%\INNternat\Python, 1-2 Minuten),
danach startet INNternat von dort schnell. Bei Updates bleibt der Ordner "Python" stehen (nur "Programm" ersetzen).

Erste Einrichtung (einmalig)
----------------------------
1. Das Zip in den Netzwerkordner entpacken, z. B. nach \\server\freigabe\INNternat.
   Alle PCs brauchen Lese- und Schreibrechte auf diesen Ordner.
2. Auf EINEM PC "INNternat starten.bat" doppelklicken.
   Weil der Ordner "Daten" noch leer ist, fragt INNternat nach dem bisherigen Ordner
   (dort, wo bisher "Start.bat" lag). "Prüfen" zeigt, was kopiert wird, "Übernehmen" kopiert es.
   Der bisherige Ordner bleibt unverändert – er ist damit zugleich die Sicherung.
   Danach INNternat einmal schließen und neu starten.
3. Auf jedem weiteren PC einmal "INNternat starten.bat" doppelklicken. Beim ersten Mal wird
   die Python-Umgebung auf diesem PC angelegt (1–3 Minuten) und eine Verknüpfung "INNternat"
   auf den Desktop gelegt. Ab dann reicht die Verknüpfung.

Voraussetzung auf jedem PC: Python 3.13 (python.org, Haken bei "Add Python to PATH").

Mehrere PCs gleichzeitig
------------------------
- Jede Änderung wird kurz für die anderen PCs gesperrt gespeichert. Speichert ein anderer PC
  gerade, wartet INNternat einige Sekunden; dauert es zu lange, kommt ein Hinweis
  "Gerade speichert …" – dann einfach noch einmal klicken.
- Die anderen PCs laden innerhalb von 30 Sekunden neu und zeigen kurz, was von wem gespeichert wurde.
- "Rückgängig" nimmt nur die eigene letzte Änderung zurück – und nur, solange danach niemand
  anderes an derselben Planung gespeichert hat.
- Darstellung, "Später" und der gewählte Standort gelten je PC
  (gespeichert unter %LOCALAPPDATA%\INNternat, ebenso Protokoll und Python-Umgebung).
- Beim ersten Start des Tages sichert genau ein PC die Daten (Daten\Sicherungen, 30 Stände je Standort).

Umzug: EIN Ordner für alle (ab 1.35)
------------------------------------
Dieser Netzwerkordner ist die einzige Installation. Alle arbeiten hier, Updates kommen nur hierher.
1. Auf EINEM PC INNternat aus diesem Ordner starten.
2. Einstellungen -> Sicherung & Verlauf -> "Daten aus bisherigem Ordner übernehmen ...".
   Als bisherigen Ordner den Ordner angeben, in dem bisher gearbeitet wurde (der mit den aktuellen Daten).
   Es geht auch der Ordner mit "Start.bat" oder eine frühere Test-Installation - INNternat findet die Daten.
   "Prüfen" zeigt, was kopiert wird.
3. Liegen hier schon Daten (z. B. vom ersten Start), "Vorhandene Daten ersetzen" anhaken. Sie werden vorher
   gesichert (Daten\Sicherungen, "vor Übernahme"); die Benutzerkonten bleiben.
4. "Übernehmen", INNternat schließen und neu starten.
5. Alte Installationen nicht mehr benutzen: auf jedem PC die alten Desktop-Verknüpfungen (z. B. "INNternat Test")
   löschen und den Autostart-Eintrag entfernen (Win+R -> shell:startup -> alte INNternat-Verknüpfungen löschen).
   Die alten Ordner bleiben unverändert als Sicherung liegen.

Benutzer und Anmeldung (ab 1.33)
--------------------------------
- Alle arbeiten mit DIESER einen Installation; jede Person meldet sich mit ihrem Konto an.
- Einrichten: Einstellungen -> Benutzer -> "Ersten Administrator anlegen". Bis dahin läuft INNternat
  ohne Anmeldung wie bisher.
- Danach legt der Administrator dort die Mitarbeitenden an: Name, Anmeldename, Rolle, Standorte.
  * Empfohlen: das Windows-Konto der Person eintragen - dann meldet INNternat sie automatisch an,
    ohne eigenes Passwort.
  * Sonst ein Startpasswort vergeben (persönlich übergeben). Es muss beim ersten Anmelden geändert werden.
- Mitarbeitende sehen nur ihre freigegebenen Standorte. Administratoren sehen alle Standorte und
  verwalten die Benutzer.
- Abmelden, Passwort ändern: unten rechts auf den eigenen Namen klicken (oder Datei -> Konto).
- Administrator-Passwort vergessen: eine leere Datei ADMIN_ZURUECKSETZEN.txt in den Ordner "Daten"
  legen. Beim nächsten Start darf unter Einstellungen -> Benutzer ein neuer Administrator angelegt
  werden; die Datei wird danach entfernt.
- Wichtig: Die Anmeldung schützt das Programm, nicht die Dateien. Wer den Ordner "Daten" im Explorer
  öffnen kann, kann die Dateien lesen. Deshalb den Netzwerkordner nur für die INNternat-Nutzer
  freigeben (IT).

Update einspielen (nur hier, in diesem Ordner)
----------------------------------------------
Immer das Paket "INNternat.zip" verwenden (nicht das Test-Paket - das legt eine getrennte Test-Installation an).
1. INNternat auf allen PCs schließen.
2. Den Ordner "Programm" löschen (NICHT "Daten").
3. Das neue Zip in denselben Ordner entpacken.
Laufende PCs, die das Update verpasst haben, zeigen "Neue Version ist eingespielt – bitte neu starten".

Test-Installation (INSTANZ.txt)
-------------------------------
Liegt neben "INNternat starten.bat" eine Datei INSTANZ.txt (z. B. mit "Test"), läuft diese Installation
getrennt von anderen: eigene lokale Umgebung unter %LOCALAPPDATA%\INNternat-Test, eigene Desktop-Verknüpfung
und eigener Autostart; das Tagesbriefing wird nicht von selbst verschickt. Liegt ein Ordner "Pakete" daneben,
werden die Python-Pakete ohne Internet daraus installiert. Liegt ein Ordner "Python" daneben
(portables Python mit allen Paketen), wird direkt damit gestartet - dann muss auf dem PC kein Python installiert sein. Näheres: INSTALLATION.txt im Installationspaket.

Das bisherige Programm (PySide)
-------------------------------
Im Netzwerkordner läuft nur die neue Oberfläche. Das bisherige Programm wird nicht mehr gestartet:
Es kennt weder die Standorte noch die Schreibsperre und würde neben den anderen PCs Daten überschreiben.
Sein Programmcode liegt weiter unter Programm\belegung, weil die neue Oberfläche Teile davon nutzt.
