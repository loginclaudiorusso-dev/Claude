INNternat – Installation zum Testen (eigenes Laufwerk, Kollegen)
==============================================================

Dieses Paket ist eine komplette, eigenständige Installation der neuen Oberfläche. Sie läuft getrennt von der
bisherigen Installation: eigener Datenordner, eigene Einstellungen, eigene Desktop-Verknüpfung „INNternat Test“.
Was hier geändert wird, landet NICHT in der echten Planung – und umgekehrt.

Voraussetzung
-------------
  Windows 10 oder 11 (64 Bit). Python muss NICHT installiert sein: Ein eigenes Python mit allen Paketen liegt im
  Ordner „Python“ und wird direkt von dort gestartet – keine Installation, keine Admin-Rechte, kein Internet.

Installieren
------------
1. Das Zip auf das gewünschte Laufwerk entpacken (Rechtsklick › „Alle extrahieren …“), z. B. nach D:\
   → es entsteht D:\INNternat_Test. Nicht direkt aus dem Zip heraus starten.
   Tipp vorher: Rechtsklick auf das Zip › Eigenschaften › unten „Zulassen“ anhaken › OK – dann fragt Windows
   beim Start nicht bei jeder Datei nach.
   Sollen mehrere Kollegen gemeinsam testen, den Ordner auf ein Netzlaufwerk legen, auf das alle
   Lese- und Schreibrechte haben.
2. Im Ordner „INNternat starten.bat“ doppelklicken.
   Der erste Start dauert etwas länger (ca. 1 Minute). Danach liegt die Verknüpfung „INNternat Test“
   auf dem Desktop – ab dann reicht die.
   Meldet Windows „Der Computer wurde durch Windows geschützt“: „Weitere Informationen“ › „Trotzdem ausführen“.
   Blockiert die IT das Starten von Programmen auf diesem Laufwerk, bitte die IT fragen bzw. einen anderen
   Ordner nehmen (z. B. unter Dokumente).
3. Beim allerersten Start fragt INNternat: „Neuer Datenordner – Daten übernehmen?“
   - Mit echten Daten testen: den bisherigen INNternat-Ordner angeben (dort, wo bisher „Start.bat“ lag),
     „Prüfen“, dann „Übernehmen“. Kopiert wird nur eine Kopie der Daten, der bisherige Ordner bleibt
     unverändert. Danach INNternat einmal schließen und neu starten.
     Achtung Datenschutz: Die Kopie enthält personenbezogene Daten – nur auf freigegebene Laufwerke legen.
   - Ohne Daten testen: „Ohne Daten beginnen“.

Was beim Testen anders ist
--------------------------
- Datenordner: „Daten“ in diesem Ordner. Der Stand der Daten ist der vom Tag der Übernahme.
- Lokale Umgebung und Einstellungen je PC: %LOCALAPPDATA%\INNternat-Test (nicht die der echten Installation).
- Das Tagesbriefing wird hier nicht von selbst per Outlook verschickt (sonst käme es doppelt).
  Mails, Entwürfe und Termine, die man selbst auslöst, funktionieren wie gewohnt – beim Testen also bitte
  bewusst einsetzen.
- „Mit Windows starten“ legt einen eigenen Eintrag an und ersetzt den der echten Installation nicht.

Wieder entfernen
----------------
  INNternat Test schließen, den Ordner INNternat_Test löschen, den Ordner %LOCALAPPDATA%\INNternat-Test löschen
  und die Desktop-Verknüpfung „INNternat Test“ löschen. Die echte Installation bleibt unberührt.
